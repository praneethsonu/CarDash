# CarDash

# Introduction
Welcome to Cardash Game, a thrilling 2D car racing game designed for speed enthusiasts and casual gamers alike. This project aims to provide an engaging racing experience with intuitive controls, vibrant graphics, and exciting gameplay mechanics.

# Usage
### To play the game:
*Launch the project in Unity.*
Click on the "Play" button in the Unity editor.
Use the arrow keys or WASD to control your vehicle.

# Technologies Used
Game Engine: Unity
Programming Language: C#
Graphics: Adobe Photoshop for assets
Sound: Audacity for sound effects
